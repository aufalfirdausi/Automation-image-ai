# Project Plan

## Project

Personal AI Workflow Orchestrator

## Goal

Build a local workflow automation platform inspired by tools such as n8n.

The system must allow users to visually create workflows and execute them locally.

## Core Stack

Frontend:
- Next.js
- TypeScript
- React Flow

Backend:
- Node.js
- TypeScript

Database:
- MySQL

AI:
- Gemini
- Ollama (later phase)

Version Control:
- Git
- GitHub

---

# Phase 1 - Foundation

Goals:
- establish repository structure
- setup frontend
- setup backend
- establish API communication
- establish MySQL connection

Do not implement:
- workflow execution
- scheduler
- Ollama
- authentication
- advanced node system
